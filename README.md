# christian-lacina.at

Website der Praxis für Integrative Gestalttherapie — Christian Lacina,
Psychotherapeut in Ausbildung unter Supervision, Wien.

Statische Website, gehostet über GitHub Pages unter der Domain
`christian-lacina.at`.

## Inhalt

| Datei              | Zweck                    |
| ------------------ | ------------------------ |
| `index.html`       | Startseite               |
| `impressum.html`   | Impressum / Offenlegung  |
| `datenschutz.html` | Datenschutzerklärung     |
| `logo-header.svg`  | Logo in der Kopfzeile    |
| `*.jpg`, `*.jpeg`  | Portrait- und Praxisfotos |

Dieses Repository enthält ausschließlich die veröffentlichten Dateien.
Entwürfe, Bildquellen und Archivmaterial werden separat und privat verwaltet.
